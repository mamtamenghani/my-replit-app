Build a clean, mobile-friendly Employee Daily Task Manager Web App with two roles: Admin (Manager) and Employee. Do not include any clock-in, clock-out, or attendance tracking features, and do not include WhatsApp integration.
1. Simple Login & Roles:
• Create a simple login screen where I can log in as the Admin, and each Employee has their own login (selecting their name and entering a 4-digit PIN or password) to see only their own tasks.
• Allow the Admin to add or remove employees.
2. Admin Dashboard (Task Assignment & Tracking):
• Give the Admin a dashboard to select any employee and add new tasks, edit tasks, or delete tasks for their day.
• Include a Time Slot field for each task covering the 10:00 AM to 8:30 PM workday (for example, "10:00 AM - 11:30 AM" or "7:00 PM - 8:30 PM").
• Show a live summary on the Admin dashboard displaying each employee's tasks for the day and whether each task is marked Done or Not Done.
• Include a date picker so the Admin can check tasks from past days or assign tasks for upcoming days.
3. Normal Admin Notifications & Activity Feed:
• Whenever an employee clicks "Done" on a task, immediately trigger a live notification message for the Admin formatted like: "[Employee Name] has completed: [Task Name] at [Time]" (for example: "Sharma has completed: Client Follow-up at 2:15 PM").
• Display these alerts in three ways on the Admin dashboard:
	1. A pop-up toast notification with a subtle chime sound when the Admin has the app open.
	2. A Notification Bell icon at the top with an unread badge count and a full history log of completed task messages.
	3. Standard Browser Push Notifications (with a simple "Enable Notifications" button for the Admin) so alerts still appear on the phone or computer screen even when the browser tab is minimized.
4. Employee Checklist View:
• When an employee logs in, show their assigned tasks for the day, sorted chronologically from 10:00 AM to 8:30 PM.
• Next to every task, display two clear, clickable status buttons: "Done" (green) and "Not Done" (red/neutral), defaulting to "Not Done" until clicked.
• Save all tasks, statuses, and notification logs in a persistent database (such as PostgreSQL or SQLite)
